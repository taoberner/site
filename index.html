À propos du projet

liO Smart Move exploite les données GTFS officielles du réseau régional pour offrir une information voyageur simple, inclusive et écologique.

Notre solution

📊

Données 100% réelles

Chargement des fichiers GTFS directement dans le navigateur — stops, routes, trips, stop_times.

🔍

Algorithme d'itinéraires

Recherche avec correspondances basée sur les horaires réels du réseau liO.

♿

Accessibilité

Profils adaptés PMR, seniors, touristes — interface personnalisable.

🗺️

Carte interactive

Leaflet.js + OpenStreetMap — arrêts réels et trajet visualisé.

Technologies

🌐 HTML5 / CSS3
⚡ JavaScript Vanilla
🗺️ Leaflet.js
